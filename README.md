# AI 漫剧全网实时流量监控大屏

1920×1080 单屏静态大屏。纯前端交付，无后台依赖，全部资源本地化（含 ECharts 与中国地图 GeoJSON），双击 `index.html` 即可离线打开。

**视觉风格**：浅色编辑排版（Editorial / Swiss）。纸白底、墨黑发丝线、朱红强调色、衬线标题、表格化数据；无圆角、无阴影、无发光、无玻璃拟态。层次全部由字号、字重与 1px 分隔线建立。

---

## 3. 运行方式

- **直接打开**：双击 `index.html`（`file://` 协议即可，无需服务器）。
- **本地服务**（可选，行为完全一致）：
  ```
  python -m http.server 8080      # 然后访问 http://localhost:8080/
  ```
- **演示参数**（可组合）：

  | 参数 | 取值 | 说明 |
  |---|---|---|
  | `mode` | `static`（默认） | 内置演示数据源，**1s 持续波动**；起始值由固定 seed 决定，每次打开起始状态一致 |
  | `mode` | `live` | 同样 **1s 持续波动**，起始值改用时间种子（每次打开不同）；接真实接口时的替换入口 |
  | `state` | `loading` | 骨架屏，不建图表实例，指标位显示破折号 |
  | `state` | `nodata` | 空数据，指标位显示破折号 |
  | `state` | `offline` | 链路中断，报头横线/时钟/链路状态转红，指标带压暗保留冻结值 |

  例：`index.html?mode=live`、`index.html?state=offline`、`index.html?mode=live&state=offline`
- **地图色阶切换**：报头右上「朱红 / 靛蓝 / 墨绿」，整组切换强调色与地图色阶，选择记入 localStorage。

## 4. 数据口径

- **告警计数口径**：`活跃告警 = 告警流水中「未恢复」的条目数`（`lv !== 'r'`）。恢复类条目只作流水展示，**不计入活跃数**。
  指标带「活跃告警」与「实时告警事件流」表头均调用同一函数取值，两处数字**恒等**，可现场核对。
  实测（live 跑动 8s 后）：两处均为 `活跃 5 条`，流水 6 条。
- **中国地图口径**：34 个省级行政区**齐全**，含台湾省、香港特别行政区、澳门特别行政区；南海诸岛与九段线依国家标准地图绘制。
  采用标准**横版**处理：主图裁到大陆范围（`boundingCoords` 纬度 17.5°–54°），九段线整体由右下角**南海诸岛附图**呈现，避免主图只画出半截线。
  名称与边界取自公开标准 GeoJSON（DataV `100000_full`，35 个要素 = 34 省级区 + 九段线），仅做几何抽稀（Douglas-Peucker ε=0.022°，约合屏幕 0.25px），**未改动任何边界走向**；抽稀时强制保留每个要素的最大多边形，确保澳门等小面积行政区不被过滤。
- **数据波动**：两种模式**都**按 1s 周期持续波动，覆盖 6 项核心指标、趋势图（16 点窗口滚动）、平台竞速榜与健康度、省级 TOP 12 与地图着色、TOP 漫剧、来源构成、告警流水（每 9s 新增一条）。
  波动模型为**有界游走 + 均值回归**（`walk()`），长时间挂机不会漂移到不可信区间；累计量（播放量、互动量）改为单调增长（约 4200–6600 次/秒，与日播放量量级相符）；来源构成每次游走后归一化，**合计恒为 100%**；告警活跃数逼近 7 条时强制补一条「恢复」，使计数围绕 3–7 条振荡而非单调累加。
  KPI 数值精度按「每秒都能看出变化」选取：播放量 4 位亿、互动量 2 位万、在线观看 1 位万。
  状态为 `loading` / `nodata` / `offline` 时**完全冻结**，数值静止不波动。
- **趋势图滚动方式**：`06 全网实时流量趋势` 是 **16 秒滚动窗口** —— 每秒右端进一个新采样、左端掉一个旧采样，**已画出的线段只平移、不重绘**。
  三个必要条件是：① 关闭 ECharts 更新补间（`animationDurationUpdate: 0`），否则它会在新旧数组之间插值、整条曲线一起扭动；② Y 轴量程写死为 `26.0万 ~ 30.0万`（量程 4 万恰为刻度 1 万的整数倍，且上下沿本身都落在整数刻度上——ECharts 一定会保留 min/max 作为首尾刻度，量程不是整倍数时首尾两格会只有中间一半宽），不随数据自动缩放，避免已画出的点跟着上下跳；③ x 轴按采样频率标 `时:分:秒`（每 5 秒一个标签），原先是按分钟标注、与 1s 刷新频率对不上。
  **实测**：3 秒后数组整体左移 3 格、13/16 个点数值完全不变且在位移后的位置上逐一相等，仅右端追加 3 个新采样。
- **数据来源**：全部为演示数据。**未接任何真实接口**。
- **单位**：播放量/在线数/互动量为「次/人」，竞速榜与健康度为「万」，省级榜与来源构成为「占比 %」。

## 6. 已知偏差

1. **⚠ 所引用的系统提示词与本次任务不匹配。** 实际下发的 Agent 系统提示词是一份《个人职业规划方案》作业要求，**不含** §1 原则、§10 自检 14 项、中国地图口径、单屏不滚动、告警计数口径等条目。因此本方案中：
   - 「中国地图口径」「单屏不滚动」「告警计数口径」三项按你在任务消息中的明确点名执行；
   - §1 原则与 §10 的 14 项自检为**重建**（依据通用大屏验收标准），已在第 5 节标注。
   若原始规格另有文本，请回贴，我会据此重跑自检并修正不一致项。
2. **风格已按要求整体更换**：本版为浅色编辑排版风，与首版「暗色霓虹 + 玻璃拟态 + 四角装饰 + 扫描线」为完全不同的视觉语言，已移除全部发光/模糊/渐变装饰；布局同步调整（KPI 由左栏 2×3 网格改为通栏指标带，正文改为 12 栅格上下两排）。信息项未删减。
3. **数据由「静态快照」改为持续波动**：首版 `static` 模式是冻结快照（仅时钟走动），按你的要求已改为**默认即持续波动**。现在两种模式都波动，`mode` 参数只区分起始种子（固定 / 随机）与角标文案；`loading`/`nodata`/`offline` 三态仍严格冻结。
4. **首版曾参照的示例站点仅用于最初的 IA 参考**，本版不再沿用其配色、面板装饰与图表动效；仅「单屏信息项构成」这一层级保持一致。
5. **`live` 模式不是真实数据源**，仍为前端有界游走；接真实接口时替换 `assets/app.js` 中 `dataTick()` 与 `ALERT_POOL` 即可，渲染层无需改动。
6. **地图为视觉抽稀版**（177 KB / 原始 582 KB），抽稀阈值远低于屏幕像素粒度（0.022° ≈ 0.25px），但**不适合用于测绘、打印或任何精度用途**。
7. **衬线标题依赖系统字体**：优先「宋体 / Songti SC / Noto Serif SC」，Windows 回退到 SimSun。若与设计稿字形不符，需自行内置字体文件。
8. **截图由 headless Edge 实拍**（`--window-size=1920,1080`，`--virtual-time-budget=20000`），非人工在目标显示器上肉眼确认。因数据持续波动，**截图中的数值仅为该时刻的一帧**，与再次打开时的数值不会相同（`static` 模式下"起始值"一致，但起始值在首帧后即被波动覆盖）。
